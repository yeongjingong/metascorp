# 인사이트(블로그) 글 등록 방법

1. 글 HTML 파일을 `blog/` 폴더에 넣습니다. (기존 `global-sourcing-checklist.html`을 복사해 내용만 바꾸면 헤더·푸터가 그대로 유지됩니다.)
2. 썸네일 이미지가 있으면 `blog/images/`에 넣습니다. (정사각형 권장, 없으면 카테고리 이름이 들어간 네이비 칸이 자동 표시)
3. `blog/posts.json`에 한 줄을 추가합니다.

```json
{
  "title": "글 제목",
  "excerpt": "목록에 보일 한두 문장 요약",
  "url": "blog/파일이름.html",
  "thumbnail": "blog/images/파일이름.webp",
  "date": "2026.11.22",
  "category": "수출 사례",
  "featured": true
}
```

- **category**는 다음 다섯 가지 중 하나로 정확히 적습니다: `공지` · `수출 사례` · `수입 사례` · `제품 정보` · `무역 정보`
  (그 외 값이나 빈칸은 `무역 정보`로 표시됩니다.)
- **featured**를 `true`로 두면 '지금 확인하면 좋은 글'에 우선 노출됩니다(최대 3개). 없으면 최신 글 순.
- 날짜 순서는 자동으로 정렬됩니다. 공개하지 않을 글은 `"draft": true`.
- 카테고리별 바로가기 주소: `blog/?c=수출 사례` 처럼 `?c=카테고리명`을 붙이면 해당 탭이 열린 상태로 열립니다.
