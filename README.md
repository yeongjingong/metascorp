## 접수 기능 연결
기존 `inquiry.html`의 `GOOGLE_SCRIPT_URL`은 여전히 `PASTE_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE`를 참조합니다. 이 값으로는 실제 접수가 되지 않으므로 운영 Apps Script URL을 입력한 후 직접 접수 테스트가 필요합니다. 기존 접수 로직은 변경하지 않았습니다.

## 메인 개선 및 블로그 연동 (2026-11-22 추가)
- 전체 폭의 이미지 없는 네이비/청록 히어로, 중앙 정렬된 기업 메시지를 적용했습니다. 사업분야 4개 사진을 각각의 정사각형 WebP 파일로 교체했습니다.
- `index.html`과 `blog/index.html`은 같은 `assets/blog-feed.js`를 사용해 `blog/posts.json`을 읽습니다. 메인은 최신 등록 글 최대 3개, 블로그는 전체를 최신순으로 표시합니다. 실제 등록 글 수가 1개면 1개만 표시하며 사업분야/수수료의 대체 카드는 없습니다.
- 새 글 등록: (1) `blog/` 아래 HTML과 필요 이미지 배포, (2) `blog/posts.json` 배열에 `title`, `excerpt`, `url`, `thumbnail`, `date`, `category`, `alt` 항목을 추가합니다. `url`은 `blog/글이름.html` 또는 `글이름.html`, `thumbnail`은 `blog/images/사진.webp` 또는 `images/사진.webp`로 작성합니다. 글 대표 이미지가 없으면 브랜드 텍스트가 표시됩니다. `date`는 `YYYY.MM.DD` 형식 권장. `draft: true` 또는 `published: false` 항목은 표시하지 않습니다. 메인 HTML/블로그 목록 HTML을 따로 편집할 필요는 없습니다. 정적 호스팅이므로 HTML 파일만 업로드하고 JSON에 등록하지 않으면 목록에 자동으로 등록되지는 않습니다.
